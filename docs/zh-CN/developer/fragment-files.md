# 片段文件（`.aviqtlfrag`）

**片段**是单独保存的一组片段物件：一张标题卡、一条效果链、一整个场景的图层内容。当工作内容需要离开它原本所在的项目时，用户要的就是它。

AviUtl 用[物件文件](./exo-object-files)（`.exo`）解决同一个问题，AviQtl-Plus 也能读取。但**写出**物件文件意味着把每个片段翻译成扩展编辑的词汇，而那套词汇更小：凡是 AviQtl-Plus 能表达、扩展编辑无法容纳的内容，都只能丢弃。为扩展编辑本来没有的东西猜一个映射更糟——文件看起来完整，渲染结果却不同。

片段文件没有这两个问题。它直接存储本项目自己的片段表示，因此没有翻译，也没有丢失。

- **文件 → 插入片段…** 把文件中的片段追加到当前场景已有片段之后，整体作为一次可撤销的编辑。
- **把片段文件拖到时间线上**会以它自身的第一帧和最低图层为基准放到指针位置。
- **文件 → 导出片段…** 写出选中的片段；没有选中时写出整个场景。

## 两种格式怎么选

| | 片段（`.aviqtlfrag`） | AviUtl 物件文件（`.exo`） |
| --- | --- | --- |
| 导入 | 无损 | 翻译；无法识别的部分变成禁用的占位项 |
| 导出 | 无损，包含全部片段 | 只写出扩展编辑能描述的物件，其余报告为跳过 |
| 能被 AviUtl 打开 | 否 | 是 |
| 能读取 AviUtl 素材 | 否 | 是 |
| 保留 AviQtl-Plus 独有参数 | 是 | 否 |

在 AviQtl-Plus 项目之间搬运工作用片段文件；只有另一端是 AviUtl 时才用物件文件。

## 文件格式

片段文件是 UTF-8 JSON，带一个与工程文件区分开的标记：

```json
{
  "format": "aviqtl.fragment",
  "version": 1,
  "settings": { "width": 1920, "height": 1080, "fps": 60, "sampleRate": 48000 },
  "clips": [
    {
      "id": 2,
      "sceneId": 1,
      "type": "text",
      "start": 30,
      "duration": 20,
      "layer": 1,
      "clipByUpperObject": false,
      "params": {},
      "audioPlugins": [],
      "effects": [ ... ]
    }
  ]
}
```

- `format` 恒为 `aviqtl.fragment`。标记缺失或不同一律拒绝读取——误把工程文件当片段打开时，会在这里被拦下，而不是产出一堆无意义的内容。
- `version` 是布局版本。读不懂的版本直接拒绝，不做猜测：半懂不懂地导入只会悄悄出错。
- `settings` 记录这些片段创作时的帧率、画面尺寸和音频采样率。导入时**不做任何缩放**；目标场景与它不一致时，导入报告会明说，而不是悄悄改变时间长度。
- `clips` 原样保存项目中的片段，包括本版本会写出但暂未读取的字段。导入时 `id` 与 `sceneId` 会被替换。

当前版本可读取的最大片段文件为 64 MiB，最大片段数量为 100,000。片段以路径引用媒体，不包含媒体本身。

由于两种文件都是 JSON，工程加载器会先检查标记：用 **文件 → 打开工程…** 打开片段文件会被拒绝，并提示应该用哪个命令打开它，而不是得到一个没有场景、片段也不知去向的工程。

## 导入做了什么

1. 每个片段都从场景自己的 id 空间分配新 id，因此同一个片段导入两次也不会冲突。
2. `start` 与 `layer` 按要求的偏移量平移。图层超出时间线末尾时会被夹到最后一条图层，而不是让导入失败。
3. 如果整块内容会落在已有物件的帧上，则整块前移，保持内部相对布局，就像拖动选择区一样。直接叠上去会让两个片段共用同一图层同一帧，渲染器只能按叠放顺序处理，而非按意图。
4. 当整块内容超出场景末尾时扩展场景，与插入同属一次可撤销的编辑。导入永远不缩短场景。

在前移、或目标场景的帧率/画面尺寸与片段创作时不一致的情况下，报告里会给出说明。

## 限制

- **一次只涉及一个场景。** 片段只携带单个场景中的片段，不携带场景定义、嵌套时长或项目的其他场景。
- **媒体靠引用，不打包。** 把片段带到另一台机器时，媒体需要一起带走或重新链接；缺失的内容由 **文件 → 管理缺失媒体** 报告。
- **没有自动迁移。** 目前只有版本 1，更新的文件会被拒绝读取，而不是部分读取。
