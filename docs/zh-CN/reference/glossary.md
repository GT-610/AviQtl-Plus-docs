# 术语表

**片段（Clip）**
: 时间线项目，具有开始帧、持续时间、图层、参数、效果和可选动画。

**效果（Effect）**
: 附加在片段上的处理步骤，按照堆栈顺序计算。

**帧（Frame）**
: 视频序列中的一张静止图像，也是时间线时间的基本单位。

**片段文件（Fragment）**
: 保存一组片段的 `.aviqtlfrag` 文件，可插入其他场景或项目而不丢失任何内容。

**关键帧（Keyframe）**
: 参数在特定时间保存的数值。关键帧之间的值可以插值计算。

**图层（Layer）**
: 时间线中的纵向位置，用于叠放和组织片段。

**对象（Object）**
: 文本、图形等不必来自导入媒体文件的生成式内容。

**播放头（Playhead）**
: 指示预览帧并供时间相关命令使用的时间线标记。

**项目（Project）**
: 保存编辑决策和源媒体引用的 `.aviqtl` 文件。

**场景（Scene）**
: 拥有自身时间线内容和设置的项目编辑环境。

**时间线（Timeline）**
: 时间横向推进、图层纵向排列的编辑视图。
