# 故障排除

首先保存项目副本，并记录应用版本、操作系统、图形硬件以及能够稳定复现问题的完整步骤。

## 应用无法启动

- 确认压缩包已经完整解压。
- Linux 上检查 Vulkan 驱动与运行环境、FFmpeg 共享库、libxkbcommon，以及 X11 或 Wayland 客户端库。
- 如果启动时提示未找到可用的 GPU 适配器，请更新显卡驱动；软件渲染器无法运行 AviQtl。
- 更新显卡驱动或 Vulkan、Metal、Direct3D 运行环境。
- 从终端启动并保留诊断输出。

## 媒体缺失

打开缺失媒体管理器，将每个缺失项替换为兼容源文件，然后保存项目。替换文件属性可能不同，因此要重新检查时间线。

## 预览空白或错误

- 将播放头移动到片段持续时间内部。
- 确认片段和图层处于可见状态。
- 暂时禁用最近添加的效果。
- 检查变换、不透明度和图层顺序。
- 使用其他播放器测试源文件。

## 编辑速度变慢

- 关闭不必要的应用，减少竞争 GPU 的工作负载。
- 判断是否由某个媒体、效果或音频插件触发。
- 编辑期间减少同时可见的重型效果。
- 保存、重启 AviQtl-Plus 并重新打开项目，再收集问题报告。

## 导出失败

- 测试较短帧范围和简单输出路径。
- 检查磁盘空间与写入权限。
- 确认项目帧率与导出帧率一致。
- 禁用最近添加的效果或插件以隔离原因。

## 报告可复现问题

使用 [AviQtl-Plus Issues](https://github.com/GT-610/AviQtl-Plus/issues)。提供能够复现问题的最小项目或步骤；上传文件或日志前删除私人媒体与个人路径。
