# 项目与媒体

## 项目设置

项目宽度、高度、帧率和音频采样率决定编辑与导出的基础环境。尽量在开始精细编辑前确定这些数值，后期修改可能影响构图、时间或输出预期。

## 项目文件与源媒体

`.aviqtl` 项目保存编辑决策，并通过路径引用源媒体，不会自动嵌入所有素材。建议在稳定的项目目录中组织文件，编辑期间不要随意改名或移动。

```text
my-video/
├── project.aviqtl
├── video/
├── audio/
├── images/
└── exports/
```

## 媒体库

时间线窗口带有一个**媒体库**，列出项目已知的文件，不论当前是否有片段引用它们。通过**显示 → 媒体库**打开，也可以用场景标签条上的**媒体**按钮切换。

- **添加媒体…** 会把文件探测一次，并把类型和源长度保存进项目。同一个文件添加两次只会更新一行，不会产生重复项。
- 每一行保存**入点**和**出点**。这两个点是每次插入时的默认范围。图片没有可定位的媒体源，所以它的范围只表示默认片段长度。
- **在播放头处插入** 把所选范围放到当前播放头和选中图层；如果该位置已有内容，会向后寻找空位。**覆盖** 则严格放在播放头处，并替换目标图层（视频还包括链接的音频图层）上该范围内的内容。两者都只产生一个撤销步骤。
- **分组** 是项目内的扁平标签，用来查找媒体。一个条目最多属于一个分组。分组可以创建、重命名、删除，也可以从条目上清除；删除或清除分组不会删除媒体，也不会改动时间线。
- 搜索框同时匹配文件名和保存的路径，分组选择器可以进一步缩小列表。

媒体库从不拥有时间线：删除一个条目不会影响任何片段，条目不存在时片段仍然可用。

## 片段文件

片段文件（`.aviqtlfrag`）是把一组片段单独保存下来，以便在别的场景或项目中再次使用。**文件 → 导出片段…** 写出选中的片段（没有选中时写出整个场景），**文件 → 插入片段…** 把它们加回来，也可以直接把文件拖到时间线上放到指针位置。

片段会保留项目里的全部内容，包括那些在 AviUtl 中没有对应物的效果和参数，因此在 AviQtl-Plus 项目之间搬运工作就用它。

AviUtl 物件文件（`.exo`）可以导入，但不能写出：**文件 → 导入 AviUtl 物件文件（兼容）…** 把 AviUtl 素材带进来，报告会说明翻译了什么、又有哪些只能作为禁用的占位项保留。

## 保存习惯

- 创建项目后立即保存。
- 大型编辑、安装包变更或导出前再次保存。
- 把项目移动到其他电脑前保留额外副本。
- 导出视频不能替代项目文件和源素材。

## 媒体缺失

即使引用文件缺失，项目仍可打开。AviQtl-Plus 会列出缺失项目，并提供管理对话框，将其替换为兼容文件。

<!-- 添加截图：![缺失媒体通知以及替换控件](/images/zh-CN/guide/projects-media/missing-media.webp) -->

重新链接文件后检查时间线，并保存更新后的项目。

替换后应检查每个受影响片段。即使文件类型兼容，新文件的时长、分辨率、帧率或声道布局也可能不同。
