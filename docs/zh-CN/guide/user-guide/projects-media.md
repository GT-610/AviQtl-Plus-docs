# 项目与媒体

## 项目设置

项目宽度、高度、帧率和音频采样率决定编辑与导出的基础环境。尽量在开始精细编辑前确定这些数值，后期修改可能影响构图、时间或输出预期。

## 项目文件与源媒体

`.aviqtl` 项目保存编辑决策，并通过路径引用源媒体，不会自动嵌入所有素材。建议在稳定的项目目录中组织文件，编辑期间不要随意改名或移动。

```text
my-video/
├── project.aviqtl
├── video/
├── audio/
├── images/
└── exports/
```

## 片段文件

片段文件（`.aviqtlfrag`）是把一组片段单独保存下来，以便在别的场景或项目中再次使用。**文件 → 导出片段…** 写出选中的片段（没有选中时写出整个场景），**文件 → 插入片段…** 把它们加回来，也可以直接把文件拖到时间线上放到指针位置。

片段会保留项目里的全部内容，包括那些在 AviUtl 中没有对应物的效果和参数，因此在 AviQtl-Plus 项目之间搬运工作就用它。

AviUtl 物件文件（`.exo`）可以导入，但不能写出：**文件 → 导入 AviUtl 物件文件（兼容）…** 把 AviUtl 素材带进来，报告会说明翻译了什么、又有哪些只能作为禁用的占位项保留。

## 保存习惯

- 创建项目后立即保存。
- 大型编辑、安装包变更或导出前再次保存。
- 把项目移动到其他电脑前保留额外副本。
- 导出视频不能替代项目文件和源素材。

## 媒体缺失

即使引用文件缺失，项目仍可打开。AviQtl-Plus 会列出缺失项目，并提供管理对话框，将其替换为兼容文件。

重新链接文件后检查时间线，并保存更新后的项目。

替换后应检查每个受影响片段。即使文件类型兼容，新文件的时长、分辨率、帧率或声道布局也可能不同。
