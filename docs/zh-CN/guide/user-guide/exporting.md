# 导出

导出会根据当前项目生成可交付文件。打开“导出媒体”前，先保存项目并预览需要导出的帧范围。

## 导出前检查

- 确认项目宽度、高度、帧率和音频采样率。
- 确认没有缺失媒体。
- 播放或定位检查完整导出范围。
- 选择空间充足且可写入的输出目录。
- 不要覆盖早期导出的唯一副本。

可用编码器取决于平台和已安装的多媒体组件。

## 帧范围

起始帧不能晚于结束帧。测试新效果、编码器或项目配置时，先导出较短范围，这比完整渲染结束后才发现问题更节省时间。

## 检查结果

使用独立媒体播放器打开导出文件，并检查：

- 图像尺寸和方向；
- 时长和帧率；
- 文本动画、效果与转场；
- 音频是否存在、同步且音量合理；
- 第一帧和最后一帧是否符合预期。

导出失败时记录完整错误信息，并阅读[故障排除](../help-and-reference/troubleshooting)。
