# 效果与动画

## 参数与效果

选中片段后会显示内容与变换参数。还可以从共享目录添加额外效果。效果属于片段，并按照效果堆栈中的位置依次计算。

使用启用开关对比添加效果前后的结果。当一个效果应当处理另一个效果的输出时，调整它们的顺序。

## 关键帧

关键帧保存片段参数在特定时间的数值。存在两个或更多关键帧时，Freya NLE 会按照所选插值方式计算中间值。

1. 选择片段和参数。
2. 将播放头移动到第一个时间点。
3. 设置数值并创建关键帧。
4. 将播放头移动到另一个时间点。
5. 修改数值并创建或更新第二个关键帧。
6. 预览两个关键帧之间的区间。

关键帧属于片段参数，并以片段内部时间进行计算。

## 动画建议

- 先练习位置、缩放、旋转或不透明度，再组合多个效果。
- 同时使用正常速度播放和逐帧检查。
- 让关键帧保持在片段持续时间以内。
- 使用少量意图明确的关键帧，避免堆积大量修正点。
- 动画结果异常时检查效果顺序。
