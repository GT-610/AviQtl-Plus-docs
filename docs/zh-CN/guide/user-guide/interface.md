# 界面概览

Freya NLE 使用多个编辑窗口，而不是固定在单个面板布局中。主预览、时间线和对象设置都可以通过应用菜单显示，并按照屏幕空间自由摆放。

<!-- 添加截图：![Freya NLE 的预览、时间线和对象设置窗口](/images/zh-CN/guide/interface/workspace-overview.webp) -->

典型工作区会同时保留预览、时间线和选中对象的设置。

## 预览

预览窗口显示当前帧中可见图层、生成对象、变换和效果合成后的结果。片段的精确时间应在时间线上判断。

## 时间线

时间从左向右推进，图层纵向排列。播放头指示预览正在显示的帧。每个片段拥有开始帧、持续时间、图层、参数、效果和动画数据。

## 对象设置

选择片段后会显示可编辑参数和效果堆栈。控件可能是数值框、滑块、颜色、文件、枚举或关键帧控件。需要精确结果时优先使用数值输入。

## 菜单与命令

菜单提供新建、打开和保存项目、导出媒体、项目设置、撤销与重做、播放、片段操作、场景操作，以及显示时间线或设置窗口的命令。

::: tip 注意输入焦点
正在文本框中输入时，空格键等快捷键可能会被文本框接收。使用播放快捷键前，先点击时间线或预览。
:::
