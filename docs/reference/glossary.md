# Glossary

**Clip**
: A timeline item with a start frame, duration, layer, parameters, effects, and
  optional animation.

**Effect**
: A processing step attached to a clip. Effects are evaluated in stack order.

**Frame**
: One still image in a video sequence and the basic unit of timeline timing.

**Fragment**
: A `.aviqtlfrag` file holding a block of clips, saved so it can be inserted into another scene or project without losing anything.

**Keyframe**
: A stored parameter value at a particular time. Values between keyframes can be
  interpolated.

**Layer**
: A vertical timeline position used for stacking and organizing clips.

**Object**
: Generated content such as text, a shape, or another visual element that does
  not have to originate from an imported media file.

**Playhead**
: The timeline marker that selects the frame shown in the preview and used by
  time-sensitive commands.

**Project**
: An `.aviqtl` file containing editing decisions and references to source media.

**Scene**
: A project editing context with its own timeline content and settings.

**Timeline**
: The editor view where time runs horizontally and layers are stacked vertically.
